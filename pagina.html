¿Cómo funciona para toda la pantalla?

  • Contenedor principal: Se aplica un contenedor con min-height: 100vh y width: 100%.
  • backdrop-filter: blur(): Esta propiedad es la clave. Aplica un desenfoque Gaussiano a todo lo que esté detrás de la capa, sin afectar a los textos o botones dentro de ella.
  • background-color (RGBA): Debe usarse un color con opacidad transparente (canal alfa), como rgba(0, 0, 0, 0.4). Nunca uses opacity de CSS puro, ya que opacará las letras.
  • Compatibilidad: Se incluye siempre la propiedad con prefijo -webkit-backdrop-filter para asegurar compatibilidad total con Safari y navegadores basados en WebKit.
